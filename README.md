# nodejs-hw-01

Bu proje, Node.js kullanarak iletişim bilgileri yönetimi için bir uygulama geliştirmeyi amaçlamaktadır.

## Özellikler

- İletişim bilgilerini oluşturma
- İletişim bilgilerini ekleme
- Tüm iletişim bilgilerini görüntüleme
- İletişim bilgisi sayısını hesaplama
- Son iletişim bilgisini silme
- Tüm iletişim bilgilerini silme

## Kullanım

Aşağıdaki komutları kullanarak uygulamayı çalıştırabilirsiniz:

- Tüm iletişim bilgilerini görüntülemek için: `npm run get-all`
- Rastgele iletişim bilgileri oluşturmak için: `npm run generate`
- Tek bir iletişim bilgisi eklemek için: `npm run add-one`
- İletişim bilgisi sayısını hesaplamak için: `npm run count`
- Son iletişim bilgisini silmek için: `npm run remove-last`
- Tüm iletişim bilgilerini silmek için: `npm run remove-all`
